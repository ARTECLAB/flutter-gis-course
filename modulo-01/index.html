📂 Estructura del Proyecto — Lo esencial
Estructura
geo_collect/
├── lib/              ← 🎯 Aquí escribimos nuestro código

Con la app corriendo, cambia cualquier texto en lib/main.dart y guarda (Ctrl + S). El cambio aparece instantáneamente en tu teléfono.

Imagina cambiar el estilo de una capa en QGIS y verlo reflejado al instante. Eso es Hot Reload.

📝 Dart que sí necesitas (ya sabes programar)

No vamos a explicar qué es una variable o un if — eso ya lo sabes. Esta tarjeta cubre solo lo que es distinto o específico de Dart/Flutter para trabajar con datos geográficos. Todo lo demás (loops, condicionales, funciones) es la misma lógica que ya conoces, con sintaxis de Dart.

⚡ Lo específico de Dart para GIS
Dart
// 1) Las coordenadas SIEMPRE son double, nunca int
double latitud = -16.4955;
double longitud = -68.1336;

// 2) El patrón que vas a reutilizar TODO el curso:
// una "fila de atributos" = Map; una "tabla" = List de Maps
List<Map<String, dynamic>> puntos = [
  {'nombre': 'Plaza Murillo', 'lat': -16.4955, 'lng': -68.1336},
  {'nombre': 'San Francisco', 'lat': -16.4983, 'lng': -68.1330},
];

// 3) Interpolación — la vas a usar para armar URLs (WMS, tiles)
String capa = 'municipios';
String url = 'https://miservidor.com/geoserver/wms?layers=$capa';

// 4) Null safety — Dart obliga a declarar si algo puede ser nulo
double? gpsLat;          // puede no tener valor todavía (sin GPS aún)
if (gpsLat != null) {
  print(gpsLat!.toStringAsFixed(4));  // el ! dice "sé que no es null"
}
El patrón List<Map> es literalmente tu tabla de atributos en memoria: cada Map es una fila, cada llave es una columna. Lo vas a ver una y otra vez hasta el módulo de exportación a GeoJSON.
⚠️
Null safety no es un capricho de Dart — es justo lo que te va a salvar más adelante cuando el GPS todavía no tiene una posición (Módulo 3) y necesitas distinguir "sin dato" de "0.0".

🤖 La IA como copiloto de código

Vas a usar asistentes de IA (Claude, Copilot, ChatGPT, etc.) durante todo el curso para escribir más rápido. La meta no es prohibirlo — es usarlo bien, sin que te genere código que no entiendes.

Cómo lo vamos a usar en este curso
  1. Primero razona tú, luego pide ayuda. Para lógica nueva, intenta una primera versión propia antes de pedirle código a la IA — si no, no aprendes a pensar en widgets/Flutter, solo a copiar.
  2. Pide explicaciones, no solo código. "Explícame por qué este widget necesita Expanded" enseña más que "dame el código del mapa".
  3. Verifica siempre 3 cosas en cualquier código que te dé una IA para Flutter: que la versión del paquete que usa existe de verdad en pub.dev, que los parámetros del widget existen (las IAs a veces "inventan" parámetros que ya no existen o nunca existieron), y que entiendes cada línea antes de pegarla.
  4. Úsala para depurar errores — pegar el mensaje de error completo de flutter run a una IA suele ser más rápido que buscarlo en Google.
🤖
Regla de oro del curso: si no puedes explicar en una frase qué hace una línea de código, no la pegues en tu proyecto — pídele a la IA que te la explique primero.

🧩 Todo en Flutter es un Widget

En QGIS construyes con capas apiladas. En Flutter, con widgets apilados y anidados.

QGIS vs Flutter — Comparación directa
Comparación
QGIS                          Flutter
─────────────────             ─────────────────
Proyecto (.qgz)         →     MaterialApp
Vista de mapa           →     Scaffold
Panel de capas          →     Column de widgets
Capa OpenStreetMap      →     TileLayer
Capa de puntos          →     MarkerLayer
Tabla de atributos      →     ListView
Barra de herramientas   →     AppBar + FloatingActionButton
Ya sabes construir interfaces — lo haces en QGIS con capas. Ahora hazlo en Flutter con la misma lógica.
📌 StatelessWidget vs StatefulWidget
StatelessWidget
No cambia después de crearse.
Ej: título de la app, ícono fijo.
StatefulWidget
Cambia mientras la app está abierta.
Ej: mapa (zoom), posición GPS.
🔄 setState — "Algo cambió, redibuja"
Dart
int _contadorPuntos = 0;

void _agregarPunto() {
  setState(() {
    _contadorPuntos = _contadorPuntos + 1;
  });
  // Le dice a Flutter: "actualiza la pantalla"
}

🏗️ Widgets Esenciales

Scaffold, Column, Row, Expanded
Dart
Scaffold(
  appBar: AppBar(title: Text('GeoCollect')),
  body: Column(
    children: [
      Expanded(          // Ocupa todo el espacio
        child: Text('Aquí va el mapa'),
      ),
      Container(          // Tamaño fijo
        height: 60,
        child: Row(       // Horizontal
          children: [
            Icon(Icons.location_on),
            Text('Lat: -16.50'),
          ],
        ),
      ),
    ],
  ),
)
💡
Expanded es clave: le dice al mapa "ocupa todo el espacio que queda". Sin él, Flutter no sabe cuánto espacio darle.

🗺️ Tu Primer Mapa Real — flutter_map

Paso 1 — Agregar dependencias

En pubspec.yaml, sección dependencies:

yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_map: ^7.0.2
  latlong2: ^0.9.1
Terminal
flutter pub get
Instalar un paquete en Flutter es como instalar un plugin en QGIS.
Paso 2 — Permiso de Internet

En android/app/src/main/AndroidManifest.xml, antes de <application>:

XML
<uses-permission android:name="android.permission.INTERNET"/>
⚠️
Sin este permiso la app se abre pero el mapa aparece en blanco. Error #1 de esta clase.
Paso 3 — Código completo del mapa

Reemplaza todo el contenido de lib/main.dart:

Dart — lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter_map/flutter_map.dart';
import 'package:latlong2/latlong.dart';

void main() {
  runApp(const GeoCollectApp());
}

class GeoCollectApp extends StatelessWidget {
  const GeoCollectApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'GeoCollect',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorSchemeSeed: Colors.teal,
        useMaterial3: true,
      ),
      home: const MapaScreen(),
    );
  }
}

class MapaScreen extends StatefulWidget {
  const MapaScreen({super.key});
  @override
  State<MapaScreen> createState() => _MapaScreenState();
}

class _MapaScreenState extends State<MapaScreen> {
  // Cambia estas coordenadas por las de tu ciudad
  final LatLng _centro = const LatLng(-16.5, -68.15);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('GeoCollect')),
      body: Column(children: [
        Expanded(
          child: FlutterMap(
            options: MapOptions(
              initialCenter: _centro,
              initialZoom: 13,
            ),
            children: [
              TileLayer(
                urlTemplate: 'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
                userAgentPackageName: 'com.example.geo_collect',
              ),
              MarkerLayer(markers: [
                Marker(
                  point: _centro,
                  width: 40, height: 40,
                  child: const Icon(Icons.location_on,
                    color: Colors.red, size: 40),
                ),
              ]),
            ],
          ),
        ),
        Container(
          padding: const EdgeInsets.symmetric(
            horizontal: 16, vertical: 12),
          color: Colors.teal.shade700,
          child: Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              Text('📍 La Paz, Bolivia',
                style: const TextStyle(color: Colors.white)),
              Text('Zoom: 13.0',
                style: const TextStyle(color: Colors.white)),
            ],
          ),
        ),
      ]),
    );
  }
}

📖 Glosario — Clase 02

WidgetCualquier elemento visual en Flutter: texto, botón, mapa, contenedor.
StatelessWidget que no cambia una vez creado (título, ícono).
StatefulWidget que puede cambiar (mapa, datos GPS, contador).
setState()Notifica a Flutter que algo cambió y debe redibujar.
ScaffoldEstructura base de pantalla: AppBar + body + botones.
Column/RowOrganizan hijos vertical (Column) u horizontalmente (Row).
Expanded"Ocupa todo el espacio disponible". Esencial para el mapa.
FlutterMapWidget de mapa interactivo que renderiza tiles.
TileLayerCapa que carga las imágenes del mapa base (tiles).
MarkerLayerCapa de marcadores/puntos sobre el mapa.
TileImagen cuadrada que forma parte del mapa. Se descargan según zoom y posición.
pubspec.yamlArchivo donde declaras las dependencias del proyecto.
💻 Práctica 02
Personaliza Tu Mapa
  1. Cambia el centro a las coordenadas de tu ciudad. En Google Maps: clic derecho → "¿Qué hay aquí?"
  2. Agrega 3 marcadores más en ubicaciones reales. Usa Colors.blue, Colors.green, Colors.orange e íconos como Icons.park, Icons.church, Icons.store.
  3. Modifica la barra inferior: nombre de tu ciudad + total de marcadores.
  4. Experimenta con el zoom: prueba 5, 13, 18. Elige el mejor para tus marcadores.
