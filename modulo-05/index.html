🎯 Objetivo

Crear un formulario profesional para capturar puntos de campo con atributos, validar y guardar los datos de forma persistente, mostrarlos en una lista editable, y combinar mapa + lista con navegación inferior. Es la clase más densa del curso — todo lo que sigue (exportación) depende de esta base de datos local.

📋 ¿Por qué necesitamos formularios?

Una coordenada sola no sirve de mucho

Capturar un punto GPS sin atributos es como tomar una foto sin descripción. En trabajo de campo necesitas registrar: ¿Qué tipo de punto es? ¿En qué estado está? ¿Alguna observación? Esos datos son los atributos.

En QGIS, cuando digitalizas un punto, se abre una ventana donde llenas los campos de la tabla de atributos. En tu app, se abre un formulario.

🧩 Widgets de Formulario

Form y GlobalKey — El contenedor y su control remoto

Form es un widget que agrupa todos los campos del formulario. GlobalKey<FormState> es como un control remoto: te permite validar todos los campos a la vez con un solo comando.

Dart
final _formKey = GlobalKey<FormState>();

Form(
  key: _formKey,
  child: Column(children: [
    // Aquí van los campos...
  ]),
)

// Validar TODO el formulario con una sola línea:
if (_formKey.currentState!.validate()) {
  // Todos los campos son válidos — guardar
}
TextFormField — Campo de texto con validación

Es un campo donde el usuario escribe texto. El validator verifica si el dato es válido y muestra un mensaje de error rojo si no lo es.

Dart
final _nombreCtrl = TextEditingController();

TextFormField(
  controller: _nombreCtrl,
  decoration: const InputDecoration(
    labelText: 'Nombre del punto',
    hintText: 'Ej: Poste eléctrico #42',
    prefixIcon: Icon(Icons.label),
    border: OutlineInputBorder(),
  ),
  validator: (valor) {
    if (valor == null || valor.isEmpty) {
      return 'El nombre es obligatorio';
    }
    return null; // null = válido
  },
)
💡
¿Qué es un TextEditingController? Es un objeto que "controla" un campo de texto. Te permite leer lo que escribió el usuario (_nombreCtrl.text) y también escribir valores por código. Cada campo de texto necesita su propio controller.
🤖
Tip con IA: escribir 4-5 validator casi idénticos (nombre, tipo, observación...) es repetitivo — buen caso para pedirle a la IA que genere las variantes una vez que tú ya escribiste y entiendes la primera. No le pidas que invente la lógica de validación del negocio (qué es obligatorio, qué rango es válido) — esa decisión es tuya.
DropdownButtonFormField — Selector de opciones

Un menú desplegable con opciones predefinidas. Ideal para campos como "tipo" o "categoría" donde las opciones son fijas.

Dart
String? _tipo; // null = nada seleccionado

DropdownButtonFormField<String>(
  value: _tipo,
  decoration: const InputDecoration(
    labelText: 'Tipo de punto',
    border: OutlineInputBorder(),
  ),
  items: ['Poste', 'Árbol', 'Edificio', 'Muestra']
    .map((t) => DropdownMenuItem(value: t, child: Text(t)))
    .toList(),
  onChanged: (v) => setState(() => _tipo = v),
  validator: (v) => v == null ? 'Selecciona un tipo' : null,
)

Cuando solo se puede elegir UNA opción de un grupo (bueno/regular/malo).

💾 Almacenamiento Local — SharedPreferences

¿Por qué guardar datos localmente?

En campo muchas veces no hay internet. Los datos deben guardarse en el teléfono y persistir aunque cierres la app. SharedPreferences guarda datos como texto (JSON) en el almacenamiento interno del teléfono.

💡
¿Qué es JSON? Es un formato de texto para representar datos estructurados. Tu lista de puntos se convierte en texto JSON para guardarse, y se reconvierte a lista de Dart al cargarse. Es como guardar una tabla de Excel como archivo CSV — los datos se convierten a texto.
yaml — pubspec.yaml
dependencies:
  shared_preferences: ^2.2.0
Dart
import 'package:shared_preferences/shared_preferences.dart';
import 'dart:convert';

// GUARDAR — convierte lista a JSON y guarda
Future<void> _guardarPuntos() async {
  final prefs = await SharedPreferences.getInstance();
  final texto = json.encode(_puntos);
  await prefs.setString('puntos_campo', texto);
}

// CARGAR — lee JSON y convierte a lista
Future<void> _cargarPuntos() async {
  final prefs = await SharedPreferences.getInstance();
  final texto = prefs.getString('puntos_campo');
  if (texto != null) {
    setState(() {
      _puntos = (json.decode(texto) as List)
        .map((e) => Map<String, dynamic>.from(e))
        .toList();
    });
  }
}
⚠️
Llama _guardarPuntos() después de cada cambio (agregar, editar, eliminar). Si solo modificas la lista en memoria pero no guardas, los cambios se pierden al cerrar la app.

📋 Lista de Registros con ListView.builder

¿Qué es ListView.builder?

Es un widget que crea una lista scrolleable. .builder significa que construye cada elemento bajo demanda — solo los que están visibles en pantalla. Es eficiente aunque tengas 1000 registros.

Dart
ListView.builder(
  itemCount: _puntos.length,
  itemBuilder: (ctx, i) {
    final p = _puntos[i];
    return ListTile(
      leading: Icon(Icons.location_on),
      title: Text(p['nombre']),
      subtitle: Text('${p['tipo']} · ${p['estado']}'),
    );
  },
)
Dismissible — Eliminar deslizando

Envuelve cada elemento en Dismissible para que el usuario pueda eliminarlo deslizando hacia un lado. Es el patrón estándar de Android para borrar.

Dart
Dismissible(
  key: Key(p['id'].toString()),
  direction: DismissDirection.endToStart,
  background: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 20),
    child: const Icon(Icons.delete, color: Colors.white),
  ),
  onDismissed: (_) {
    setState(() => _puntos.removeAt(i));
    _guardarPuntos();
  },
  child: ListTile(/* ... */),
)

🧭 Navegación y Vista Combinada

Navigator — El sistema de pantallas de Flutter

Tu app tiene varias pantallas: Mapa, Formulario, Lista. Navigator controla la navegación entre ellas, como una pila (stack) de cartas:

push
Pone una pantalla nueva encima.
"Ir al formulario"
pop
Quita la pantalla de encima.
"Volver atrás"
Dart
// Ir al formulario
Navigator.push(context, MaterialPageRoute(
  builder: (_) => FormularioPunto(posicion: _gps!),
));

// Volver atrás (dentro del formulario)
Navigator.pop(context);
BottomNavigationBar + IndexedStack — Mapa ↔ Lista

Como Google Maps tiene "Explorar" y "Guardados" abajo, tu app tendrá "Mapa" y "Datos".

Dart
int _pantalla = 0;

Scaffold(
  body: IndexedStack(
    index: _pantalla,
    children: [
      _buildMapa(),   // índice 0
      _buildLista(),  // índice 1
    ],
  ),
  bottomNavigationBar: BottomNavigationBar(
    currentIndex: _pantalla,
    onTap: (i) => setState(() => _pantalla = i),
    items: const [
      BottomNavigationBarItem(
        icon: Icon(Icons.map), label: 'Mapa'),
      BottomNavigationBarItem(
        icon: Icon(Icons.list), label: 'Datos'),
    ],
  ),
)
💡
¿Qué es IndexedStack? Es un widget que tiene varios hijos pero solo muestra uno a la vez (el del índice indicado). Los demás están ocultos pero mantienen su estado — el mapa no se reinicia al cambiar a la lista.

📄 ¿Qué es GeoJSON?

El formato universal de datos geográficos

GeoJSON es un formato de texto para representar datos geográficos. Es el formato más universal de intercambio en GIS moderno: lo leen QGIS, ArcGIS, PostGIS, Google Maps, Leaflet y cualquier herramienta actual.

Un archivo GeoJSON es simplemente texto JSON organizado con una estructura específica:

GeoJSON
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [-68.1336, -16.4955]
      },
      "properties": {
        "nombre": "Poste eléctrico #42",
        "tipo": "Poste",
        "estado": "Bueno"
      }
    }
  ]
}
FeatureCollection
La colección completa = una capa en QGIS
geometry
DÓNDE está el punto (coordenadas)
properties
QUÉ es el punto (atributos)
⚠️
¡CUIDADO con el orden de coordenadas! En GeoJSON las coordenadas van [longitud, latitud] — al revés de como las usamos en Flutter (LatLng(lat, lng)). Si tus puntos aparecen en el océano, es por esto.
Un FeatureCollection de GeoJSON es exactamente como una capa vectorial de QGIS: una colección de geometrías, cada una con sus atributos en la tabla.

⚙️ Generar GeoJSON en Dart

Función que convierte tus puntos a GeoJSON
Dart
String generarGeoJSON(List<Map<String, dynamic>> puntos) {
  final features = puntos.map((p) {
    return {
      'type': 'Feature',
      'geometry': {
        'type': 'Point',
        'coordinates': [
          p['longitud'],  // ← lng primero
          p['latitud'],   // ← lat segundo
        ],
      },
      'properties': {
        'nombre': p['nombre'],
        'tipo': p['tipo'],
        'estado': p['estado'],
        'fecha': p['fecha'],
      },
    };
  }).toList();

  final geojson = {
    'type': 'FeatureCollection',
    'features': features,
  };

  return const JsonEncoder.withIndent('  ').convert(geojson);
}

📤 Guardar y Compartir

Nuevas dependencias

dependencies:

💡
path_provider te da la ruta de las carpetas del teléfono (documentos, caché, etc.). share_plus abre el menú de compartir de Android (WhatsApp, email, Drive, etc.).
Guardar archivo y compartir
Dart
import 'dart:io';
import 'package:path_provider/path_provider.dart';
import 'package:share_plus/share_plus.dart';

Future<void> _exportar() async {
  // 1. Generar el texto GeoJSON
  final texto = generarGeoJSON(_puntos);

  // 2. Obtener carpeta de documentos
  final dir = await getApplicationDocumentsDirectory();

  // 3. Crear archivo con nombre único
  final ts = DateTime.now().millisecondsSinceEpoch;
  final archivo = File('${dir.path}/geocollect_$ts.geojson');
  await archivo.writeAsString(texto);

  // 4. Abrir menú de compartir
  await Share.shareXFiles(
    [XFile(archivo.path)],
    text: 'GeoCollect — ${_puntos.length} puntos',
  );
}

📦 Configurar y Generar el APK

Identidad de la app

En android/app/src/main/AndroidManifest.xml, cambia el nombre visible:

XML
<application
    android:label="GeoCollect"
    ...>

En android/app/build.gradle, sección defaultConfig, define el identificador único y la versión:

Gradle
defaultConfig {
    applicationId "com.tuempresa.geocollect"
    minSdkVersion 21
    targetSdkVersion 34
    versionCode 1
    versionName "1.0.0"
}
¿Qué es un APK y cómo se genera?

APK = Android Package. Es el archivo que se instala en un teléfono Android — como un .exe en Windows. Al generarlo, Flutter compila tu código Dart a código nativo, incluye los recursos, y empaqueta todo en un solo archivo.

Terminal
flutter build apk --release

El APK se genera en:

Ruta
build/app/outputs/flutter-apk/app-release.apk
💡
El build tarda 2-3 minutos. La versión release es más pequeña y rápida que la versión debug que usamos en desarrollo. Para publicar en Google Play necesitarías además firmar el APK con un keystore propio — para instalar directamente en teléfonos (lo que hace este curso) no es obligatorio.

Para instalar en otro teléfono Android:

1. Envía el archivo APK por WhatsApp, Google Drive o cable USB
2. En el teléfono receptor: Configuración → Seguridad → "Fuentes desconocidas" → Activar
3. Abre el archivo APK y presiona "Instalar"
4. ¡La app está lista para usar!

🚀 Hacia dónde llevar GeoCollect

El curso termina, el proyecto no tiene por qué hacerlo

GeoCollect ya es una app de campo funcional de punta a punta. Algunas direcciones para seguir creciéndola por tu cuenta, usando IA como copiloto igual que en el curso:

  1. Modo offline real: cachear los tiles del mapa para zonas sin señal (paquetes como flutter_map_tile_caching).
  2. Sincronización: cuando vuelve el internet, subir automáticamente los puntos capturados a tu GeoServer vía WFS-T.
  3. Más formatos de exportación: además de GeoJSON, exportar a KML o CSV con coordenadas.
  4. Fotos por punto: adjuntar una foto de cámara a cada registro capturado (paquete image_picker).
  5. Pulir la identidad visual: ícono y splash screen propios, tema oscuro con Material 3.
🤖
Recapitulando el hilo de IA del curso: la usaste para razonar sintaxis nueva (Módulo 1), generar variantes de diseño (popups, Módulo 2), depurar errores de Gradle/GPS (Módulo 3), verificar fórmulas con casos de prueba (Módulo 4) y acelerar código repetitivo de validación (este módulo).
